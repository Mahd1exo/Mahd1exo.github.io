## 🔭 This repository

The source of **[mahd1exo.github.io](https://mahd1exo.github.io)** — my portfolio. Hand-written HTML, CSS
and vanilla JavaScript: no framework, no build step, no tracking, and no third-party JS at runtime.

```
index.html        markup + inline SVG icon sprite
css/style.css     design tokens, dark/light themes, layout
js/config.js      résumé content as structured data
js/main.js        theme, nav, scroll spy, reveal, counters, contact form
```
