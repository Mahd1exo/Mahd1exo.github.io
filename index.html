01 About

Fast systems, measured honestly.

I'm a Software Engineering Technology student at Conestoga College, ranked first in my cohort by term GPA with a 97% average across all courses — and I've spent every term since 2022 shipping production code alongside it.

At SOTI I work on performance engineering for MobiControl: in-house automation tooling that cut manual test effort by 80%, staging sanity and health checks accelerated 84% at equal accuracy, and CPU, memory and SQL hotspots isolated per release with JMeter, dotTrace and Grafana.

Before that I co-founded three products — Eyval (Velocity Summer 2026), Oktav (Velocity Deep Tech, Top 10) and Versall — building Go, .NET and Node backends, gRPC services, Kafka eventing and autoscaled real-time WebSocket infrastructure.
